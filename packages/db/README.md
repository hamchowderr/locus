# @locus/db

Drizzle schema and migrations for the two kinds of database. Design: vault notes
`Locus Data Model` and `Locus Phase 0`.

| Database | Holds | Migrated by |
|---|---|---|
| **control** (one) | Better Auth's tables, the client registry (`location`), staff client access (`member_location`), site index, the three connections (Infisical paths, never token values), audit log, each tenant's schema state | Drizzle's migrator — `migrateControlDb` |
| **tenant** (one per client) | `site_file`, `site_version`, `generation_run`. Never any GHL data | our runner — `migrateTenants` |

## Changing a schema

```
pnpm --filter @locus/db generate         # writes migrations/control and migrations/tenant
```

A test fails if a schema change has no migration. `src/control/auth-schema.ts` is generated by
Better Auth's CLI (`pnpm --filter @locus/auth generate:schema`) — never edit it; add anything it
lacks as a custom migration (see `0001_invitation_inviter_index.sql`). Every foreign key is
indexed, and a test enforces that: Turso bills rows scanned.

## Clients

- `provisionLocation` creates the client's database, registers it, migrates it, marks it active.
- `offboardLocation` deletes the database, then the row (which cascades).
- `migrateTenants` walks every client **from our registry** and applies what each is missing.
  It stores the full applied hash set per client, so a migration skipped in the middle is
  detected and repaired — Drizzle's migrator only checks the newest and would miss it. One
  client failing is recorded in `location_schema_version.last_error` and never stops the rest.

`TenantProvisioner` creates, grants and deletes a client's database. `LocalProvisioner` uses one
SQLite file per client and **isolates nothing** — a test that claims to prove a tenancy
boundary must run against Turso.

## Not here yet

- `TursoProvisioner` and `LOCUS_PROVISIONER=local|turso` (needs a Turso org and Platform token).
- Better Auth's Stripe `subscription` table (comes with billing).
- Concurrency in the tenant runner — it walks clients one at a time.
